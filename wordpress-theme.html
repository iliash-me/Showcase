FAQ

Frequently asked questions

Can't find what you're looking for? Our support team is happy to help.

Do I need coding skills?

Not at all. Import a starter site with one click and edit everything visually with Elementor and the WordPress Customizer.

Do I need Elementor Pro?

No. Aurelia works with the free version of Elementor. Our custom widgets cover most features people buy Pro for.

Can I import a demo on an existing site?

We recommend importing on a fresh WordPress install to avoid conflicts with existing content. You can also import individual pages.

Is it compatible with WooCommerce?

Yes — every WooCommerce page is fully designed, and the theme is tested with each new WooCommerce release.

How do updates work?

Register your purchase code and you'll get update notifications and one-click updates right inside your WordPress dashboard.

Is the theme GPL licensed?

Yes. The PHP code is 100% GPL. Images and some assets may be under separate licenses, as described in the documentation.
