Requirements

Runs on almost any hosting

Shared hosting, VPS or cloud — if it runs Laravel, it runs Quillo. The web installer handles the rest.

Server requirements

  • PHP8.2 or higher
  • DatabaseMySQL 5.7+ / MariaDB 10.3+
  • PHP extensionsBCMath, cURL, GD, Mbstring, OpenSSL, PDO, Zip
  • Cron jobsRequired (queues & renewals)
  • SSL certificateRecommended
  • AI providerYour own API key(s)

Up and running in minutes

  1. Upload & create a databaseUpload the files to your server and create an empty MySQL database.
  2. Run the web installerOpen yourdomain.com/install — it checks requirements and sets everything up.
  3. Add your keys & launchEnter your AI provider and payment gateway keys in the admin panel.
# Add this cron entry for queues & renewals * * * * * php /path/to/quillo/artisan schedule:run >> /dev/null 2>&1

FAQ

Frequently asked questions

Can't find what you're looking for? Our support team is happy to help.

Do I need my own API keys?

Yes. Quillo connects to AI providers using your own API keys, so you control costs and pricing. Keys are added in the admin panel.

Can I charge my users?

Yes — but you'll need the Extended License if your end users pay for access, such as subscriptions or credit packs.

Is the source code encrypted?

No. You get the full, unencrypted Laravel source code, so you can customize and extend everything.

Will it run on shared hosting?

Yes, as long as your host supports PHP 8.2+, MySQL and cron jobs. A VPS is recommended for high traffic.

Do you offer installation?

Yes. Installation is free with the Extended License, and available as a paid service for Regular License buyers.

How do updates work?

Download the latest version from your marketplace account and follow the one-click update steps in the documentation.
