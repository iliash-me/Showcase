Requirements

Install on your own server — or locally

Run it on shared hosting, a VPS or a local machine on your store network.

Server requirements

  • PHP8.2 or higher
  • DatabaseMySQL 5.7+ / MariaDB 10.3+
  • PHP extensionsBCMath, cURL, GD, Intl, Mbstring, PDO, Zip
  • Web serverApache or Nginx
  • Local installXAMPP / Laragon supported
  • Printer (optional)ESC/POS compatible

Up and running in minutes

  1. Upload the filesUpload to your hosting or copy into your local server folder.
  2. Run the installerOpen the site in your browser — the installer checks requirements and creates the database tables.
  3. Set up your businessAdd your store details, tax rates, currency and staff accounts, then start selling.

FAQ

Frequently asked questions

Can't find what you're looking for? Our support team is happy to help.

Can I manage multiple stores?

Yes. Add unlimited stores and warehouses, track stock separately for each and transfer stock between them.

Will it work with my scanner and printer?

Most likely. Any keyboard-mode barcode scanner works, and thermal printers are supported via ESC/POS or standard browser printing.

Can I run it without internet?

Yes — install it on a local computer (for example with XAMPP or Laragon) and use it over your store network.

Is the source code included?

Yes, you get the full unencrypted Laravel source code to customize as you need.

Does it support my currency and taxes?

Yes. Configure any currency, multiple tax rates, inclusive or exclusive tax, and translate the interface into your language.

Do you help with installation?

Installation is free with the Extended License and available as an affordable service for Regular License buyers.
